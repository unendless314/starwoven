# 已知問題

以下項目為 Demo 內容或外部設定待確認事項，非程式設計問題。

## 1. 固定循環課程價格不一致

- **狀態**：✅ 已解決（2026-09-29 由業主定案）
- **影響位置**：首頁與「活動與課程」頁
- **說明**：原首頁文案顯示「包 4 堂 1800 元」與部分課程頁「包月四堂 2000 元」存在前後矛盾，且單堂收費語意不夠明確。
- **處理結果**：業主正式定案——固定循環課程統一為每期 **4 堂 2000 元**（採包月制，必須以月為單位報名，不開放單堂單堂上課）。已同步更新 `decisions.md`（DEC-005）、`content_inventory.md`、首頁及活動課程頁面。

## 2. LINE 社群卡片連結待補

- **狀態**：✅ 已解決（2026-09-29 由業主定案）
- **影響位置**：全站頁尾（Footer）
- **說明**：原頁尾包含 4 張 QR Code 卡片（包含待補邀請連結之 LINE 社群卡片）。
- **處理結果**：業主正式定案——移除頁尾所有 QR Code 大卡片，簡化為 5 大社群 Favicon 圖示按鈕（Instagram、Facebook、Threads、LINE、YouTube），並將 Google Map 地標導航連結移至左方地址按鈕。原待補之 LINE 社群卡片已隨版面重構一併移除，關閉此項待辦。

## 3. 首頁元件與內容資料待拆分

- **狀態**：後續優化
- **影響位置**：`src/pages/index.astro`
- **說明**：首頁目前同時包含素材設定、課程與許願池資料、各區塊版型及樣式，檔案現已約 890 行（許願池卡片已拆出為 `CourseWishlistCard.astro`，但資料陣列與各 section 版型仍在頁面內）。Demo 階段結構仍易讀，但持續增加內容後會降低維護效率。
- **處理方式**：
  1. 將課程卡、評價卡等重複版型拆成可重用元件（許願池卡已拆分，可比照辦理）。
  2. 將課程價格、報名連結、人物資料與素材路徑集中至單一資料檔。
  3. 後續加入內容格式驗證或基本檢查，避免跨頁資訊不一致。

## 4. 全站 OG 分享圖檔案尚未存在

- **狀態**：待補素材
- **影響位置**：全站各頁（`src/layouts/Layout.astro` 預設 `ogImage = '/assets/og-image.jpg'`）
- **說明**：各頁面均未傳入 `ogImage`，全站共用 Layout 預設值，但 `public/assets/og-image.jpg` 尚未生成；社群平台（LINE / Facebook）抓取分享縮圖時會 404。
- **處理方式**：
  1. 由素材管線產出 1200×630 品牌 OG 圖，依全站 WebP 強制規範輸出為 `og-image.webp`（Q85）放入 `public/assets/`，並同步把 `Layout.astro` 預設 `ogImage` 改為 `/assets/og-image.webp`；若目標分享平台不相容 WebP，再例外評估 JPG 並記錄於 `decisions.md`。
  2. 或於各頁 `<Layout ogImage="...">` 個別指定既有素材。
